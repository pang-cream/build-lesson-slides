# Physics

Use: phenomenon -> idealized model -> variables -> law -> derivation or evidence -> graph -> experiment -> worked problem -> transfer.

## Layout

- Pair a physical diagram with the governing relation.
- Draw force diagrams, rays, circuits, and coordinate systems precisely.
- Use Python for measured curves and simulations; use TikZ for schematic geometry.

## Required Checks

- State assumptions, reference frames, sign conventions, and applicable regimes.
- Check dimensions and units.
- Distinguish a definition, empirical law, model, and derived result.
- Recalculate examples and verify graph axes.
- Include experimental controls, uncertainty, and safety when relevant.
