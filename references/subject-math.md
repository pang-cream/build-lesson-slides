# Mathematics

## Route

- Concept: intuition -> definition -> representations -> properties -> example.
- Formula: problem -> prerequisites -> derivation -> conditions -> secondary conclusions -> examples.
- Theorem: motivation -> statement -> proof idea -> proof or derivation -> consequences -> application.
- Geometry: figure -> known/target -> construction or transformation -> proof -> variant.

## Layout

- Use formulas and diagrams as the main visual language.
- Show one transformation per derivation step.
- Keep annotations close to the affected term.
- Use TikZ or PGFPlots for exact geometry and functions; use Matplotlib for numeric plots.

## Required Checks

- State domains and conditions.
- Define every symbol before use.
- Recalculate examples and special cases.
- Keep equivalent forms and sign conventions consistent.
- Include common mistakes and at least one transfer example.
