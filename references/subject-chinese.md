# Chinese

## Classical Chinese

Use: context -> segmented original -> key words -> sentence pattern -> translation -> paragraph role -> theme. Pair original text on the left with annotations and translation on the right. Color-match a word with its explanation.

## Poetry

Use: author and setting -> reading rhythm -> imagery -> key diction -> technique -> emotion -> theme. Keep the poem visible and short; use imagery as support rather than replacement.

## Modern Prose

Use: overall perception -> paragraph structure -> key sentences -> rhetoric or characterization -> relationships -> theme -> evidence-based interpretation.

## Writing

Use: task analysis -> idea selection -> structure -> evidence or examples -> model fragment -> revision comparison -> checklist.

## Required Checks

- Verify original wording, punctuation, author, and source edition.
- Separate literal translation from interpretive explanation.
- Explain words in their local context.
- Avoid placing an entire long article on slides; segment it.
- Keep longer copyrighted modern passages out unless the user supplied them or permission is clear.
