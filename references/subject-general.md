# General Subject

Classify the lesson as one or more of:

- Concept: motivation -> definition -> examples -> boundaries -> transfer.
- Process: purpose -> inputs -> stages -> outputs -> failure points -> application.
- Text: context -> segmentation -> close analysis -> structure -> interpretation.
- Case: context -> evidence -> decision or explanation -> outcome -> reflection.
- Skill: goal -> demonstration -> guided attempt -> independent attempt -> rubric.

Prefer the form native to the discipline: notation, evidence, source text, experiment, artifact, performance, or practice. Do not force a formula-first structure onto non-quantitative subjects.

Record that the general profile was used so a dedicated subject profile can be added later if repeated demand appears.
