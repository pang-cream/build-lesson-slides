# English

## Route

- Vocabulary: context -> meaning -> form -> collocation -> contrast -> production.
- Grammar: communicative need -> form -> meaning -> constraints -> comparison -> guided practice -> production.
- Reading: prediction -> structure -> key evidence -> language focus -> inference -> theme.
- Writing: prompt -> audience and purpose -> outline -> language choices -> model -> revision.

## Layout

Use paired examples, sentence highlighting, before-and-after revision, and short text annotation. Keep instructions in the learners' appropriate language level.

## Required Checks

- Verify grammar, register, collocation, and pronunciation notation.
- Separate rule from usage tendency and exception.
- Use natural example sentences.
- Keep reading excerpts short and preserve their context.
- Include learner production, not only recognition.
