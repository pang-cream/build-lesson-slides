# Geography

Use: location -> spatial distribution -> characteristics -> causes -> process -> impacts -> response -> case transfer.

## Layout

Use maps, profiles, climate or population graphs, process arrows, and regional comparisons. Keep legends, scale, orientation, units, and data dates visible.

## Required Checks

- Verify geographic names, coordinates, scale, and map orientation.
- Distinguish spatial pattern from causal explanation.
- State the time period and data source for changing indicators.
- Avoid AI-generated maps for exact boundaries or quantitative claims.
- Connect human and physical factors when both matter.
