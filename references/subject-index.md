# Subject Index

Identify both the subject and the lesson type. Subject alone is not enough.

| Signals | Read | Common lesson types |
|---|---|---|
| 数学、代数、函数、几何、概率、公式、证明 | subject-math.md | concept, formula, theorem, geometry, problem solving |
| 语文、文言文、古诗、现代文、作文、阅读 | subject-chinese.md | classical text, poetry, prose, writing |
| 英语、词汇、语法、阅读、写作、口语 | subject-english.md | vocabulary, grammar, reading, writing |
| 物理、力学、电学、光学、热学、实验 | subject-physics.md | law, model, derivation, experiment, problem solving |
| 化学、反应、元素、方程式、实验 | subject-chemistry.md | concept, reaction, experiment, calculation |
| 生物、细胞、遗传、生态、生理 | subject-biology.md | structure, process, regulation, experiment |
| 历史、朝代、事件、人物、制度 | subject-history.md | event, person, institution, historical interpretation |
| 地理、地形、气候、区域、人口、产业 | subject-geography.md | region, distribution, process, case study |
| 计算机、编程、算法、数据结构、网络 | subject-computer-science.md | concept, algorithm, code, system |
| No clear match | subject-general.md | concept, process, text, case, skill |

Resolve mixed lessons by their main learning objective. For example, route mathematical modeling in physics to physics, and route rhetorical analysis of a science article to Chinese or English.

If no dedicated profile matches, use subject-general.md and state in the working notes that the general profile was used. Do not invent a new profile during a normal deck build.
