# Biology

Use: structure -> function -> process -> regulation -> evidence -> variation or exception -> application.

## Layout

Use labeled structures, process flows, comparison tables, and evidence charts. Reveal a process across separate slides when a single diagram would become crowded.

## Required Checks

- Keep levels of organization explicit.
- Distinguish correlation, mechanism, and evidence.
- Verify direction, sequence, inputs, outputs, and feedback.
- Label diagrams accurately and avoid decorative biological imagery when precision matters.
- Include experimental variables and controls when explaining evidence.
